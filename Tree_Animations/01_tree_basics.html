Vocabulary — click a term to see it on the tree

A tree is a set of nodes joined by edges with three rules: one node is the root, every other node has exactly one parent, and there are no cycles. A tree with N nodes always has exactly N − 1 edges.

Depth is measured downwards from the root. Height is measured upwards from the deepest leaf. LeetCode counts nodes, so an empty tree has height 0 and a single node has height 1. Written notes usually count edges, where a single node has height 0. Both are correct — say which one you mean.

Input format

Values are read level by level, left to right. Use # for an empty child. Every node listed consumes two slots — its left child, then its right child.

1 2 3root 1, children 2 and 3
1 2 3 4 5 # 6the course tree
1 # 2 # 3right-skewed chain
5a single node: it is the root and a leaf
